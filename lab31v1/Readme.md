# Звіт до лабораторної роботи 31: Тестування з Moq

## Мета роботи
Навчитися створювати mock-об'єкти за допомогою бібліотеки Moq для тестування класів із залежностями, а також використовувати методи Setup та Verify.

## Виконання роботи

**1. Створення інфраструктури проєкту**
Згідно з першим варіантом створено основний проєкт та тестовий проєкт на базі xUnit. До тестового проєкту додано пакет Moq для створення фіктивних залежностей.

**2. Реалізація бізнес-логіки з Dependency Injection**
Розроблено клас OrderService, який обробляє замовлення. Цей клас має дві зовнішні залежності: інтерфейс IOrderRepository для взаємодії з базою даних та інтерфейс IEmailService для відправки електронних листів. Ці залежності передаються виключно через конструктор, що забезпечує гнучкість архітектури.

**3. Налаштування тестів**
Написано 8 незалежних юніт-тестів. Для ізоляції логіки сервісу створено mock-об'єкти обох інтерфейсів. За допомогою методу Setup налаштовано імітацію різних відповідей від бази даних. Метод Verify застосовано для контролю викликів: він гарантує, що лист відправляється лише за умови успішного збереження замовлення.

**4. Тестовані сценарії**
Покрито як успішні, так і проблемні випадки роботи сервісу:
1) успішне створення замовлення;
2) обов'язкова відправка листа при успішному збереженні;
3) коректна обробка помилки при збої збереження в базу;
4) блокування відправки листа у разі збою збереження;
5) відмова в обробці замовлення з нульовою сумою;
6) перевірка статусу успішно обробленого замовлення;
7) перевірка статусу замовлення в очікуванні;
8) обробка запиту на перевірку неіснуючого замовлення.

## Результати перевірки
Запуск тестів через консоль підтвердив стовідсоткове проходження всіх розроблених сценаріїв. Усі 8 тестів виконані без помилок. Логіка сервісу працює абсолютно коректно в ізольованому середовищі.

## Висновок
Під час виконання лабораторної роботи засвоєно принципи модульного тестування класів із зовнішніми залежностями. На практиці доведено, що шаблон Dependency Injection є ключовим для побудови тестопридатного коду. Бібліотека Moq дозволила швидко зімітувати поведінку бази даних та поштового сервісу без їх реального підключення. Вимоги завдання виконані в повному обсязі.
